# Three-Minute Video Script

The video file is intentionally not included in this repository. Record the following sequence and keep the final video under three minutes.

## 0:00-0:20 - Problem

Show the landing screen or a long annual report.

Narration:

“Financial analysts spend hours extracting figures from long company reports. An AI can make extraction faster, but a plausible number can still be wrong. SOLFV makes the extraction auditable before it becomes a financial conclusion.”

## 0:20-0:45 - Core insight

Show the pipeline or reconciliation panel.

Narration:

“The model extracts. The arithmetic decides. SOLFV validates extracted figures against accounting relationships, labels every figure by trust, and quarantines values that fail.”

## 0:45-1:20 - Doctored report demo

Run the verified fixture, then the doctored fixture.

Narration:

“The verified report produces trusted figures and ratios. In the doctored version, one balance-sheet number changes. The system does not continue with a misleading risk score. It shows the failed check, quarantines the affected figures, and withholds dependent ratios.”

## 1:20-1:45 - Provenance and market intelligence

Show click-to-source, then the live crypto market panel.

Narration:

“Every number is traceable to its source cell. SOLFV also provides live crypto-market intelligence, including prices, market capitalization, volume, movement, and Solana pool activity.”

## 1:45-2:30 - Solana x402 flow

Show the paper-order action, HTTP 402 response, Phantom, and the receipt.

Narration:

“Analysis is free. When a user creates an optional paper investment, SOLFV returns an HTTP 402 payment challenge. Phantom signs a small Devnet USDC payment with the verification memo. The backend checks the transaction on Solana and records it in Supabase before creating the paper receipt.”

## 2:30-2:50 - What is simulated

Show the receipt disclaimer.

Narration:

“This prototype does not buy or custody cryptocurrency. The Solana payment demonstrates the x402 payment rail, while the investment outcome is a paper transaction using live reference pricing.”

## 2:50-3:00 - Close

Show the product name and tagline.

Narration:

“SOLFV turns financial documents into evidence-led intelligence, then extends that intelligence into transparent crypto research and machine-native payment workflows. The model extracts. The arithmetic decides.”
