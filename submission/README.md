# SOLFV Submission Package

This folder contains the material needed to prepare the Devpost and Solana Lab submissions.

- `DEVPOST_PROJECT_DESCRIPTION.md` - copy-ready project description.
- `SOLANA_TRACK_SUBMISSION.md` - Solana Lab submission text and evidence.
- `LOCAL_DEMO_RUNBOOK.md` - judge setup, run, and evaluation instructions.
- `TECHNICAL_SCOPE.md` - implementation status, architecture, and limitations.
- `video/VIDEO_SCRIPT.md` - three-minute video script and shot list. The video file is intentionally not included.

Replace placeholders such as the deployed demo URL and team details before submitting.
